# 0x0a. C - Malloc, free

## Description
This project covers dynamic memory allocation in C using `malloc` and `free`. It explores how to allocate memory on the heap, handle allocation failures, and prevent memory leaks using Valgrind.

## Tasks
- **0-create_array.c**: Creates an array of chars and initializes it.
- **1-strdup.c**: Returns a pointer to a newly allocated space in memory (string duplicate).
- **2-str_concat.c**: Concatenates two strings.
- **3-alloc_grid.c**: Returns a pointer to a 2D array of integers.
- **4-free_grid.c**: Frees a 2D grid created by alloc_grid.
